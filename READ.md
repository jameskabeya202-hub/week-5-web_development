# My Budget Tracker

A static personal budget tracker page built with HTML and CSS.

## What the project includes

- A page heading, description, and icon image
- An expense form with name, amount, and category fields
- A category dropdown with Food, Transport, Rent, Entertainment, and Other
- An expense table with Name, Amount, Category, and Date columns
- Five sample expenses
- A collapsible “How to use this tracker” section
- An embedded YouTube budgeting video
- CSS styling for the form, table, and page sections

## Files

- `index.html` contains the page structure, form, expense table, image, collapsible section, and video.
- `style.css` contains the visual styles and advanced CSS selectors.

## How to view

Open `index.html` in a web browser. The image and embedded video need an internet connection.

The Add Expense button is visual only. Adding new expenses will be implemented in a later project week.


# SpendWise Budget Tracker

A static personal finance dashboard built with HTML and CSS.

## What it includes

- A sidebar with dashboard navigation
- A header with a monthly spending summary
- Six spending category cards: Food, Transport, Rent, Entertainment, Savings, and Utilities
- A responsive layout using CSS Grid and Flexbox
- CSS variables for the color theme
- Hover and keyboard focus effects on the category cards
- A dark theme based on the device’s color scheme

## Project files

- `index.html` contains the dashboard structure and sample financial information.
- `style.css` contains the layout, colors, responsive styles, and card interactions.
- `README.md` describes the project and its files.

## How to view

Open `index.html` in a browser. Use the browser’s DevTools Device Toolbar to check the layout below 768px.
